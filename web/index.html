9918 Studio の使い方

SCREEN 0〜3とスプライトMode 1専用の編集画面です。左の部品一覧から選び、中央で描きます。「この部品で配置」でスタンプ配置に切り替えます。

start.cmd で起動。編集は data/project.json に自動保存されます。別名保存は「プロジェクト保存」。参考画像もプロジェクトに含まれます。

キーボード

B 鉛筆 / E 消しゴム / F 塗りつぶし / L 線 / R 四角 / I スポイト
Ctrl+Z 戻す / Ctrl+Y やり直す / Ctrl+S プロジェクト保存

MSXの制約

「検証」は全フレームを検査します。色数を超えた位置は赤く表示。バイナリ出力前に修正してください。制約への自動調整は元に戻せます。PNGやプロジェクト保存は違反があっても可能です。

MCP接続

このアプリを起動したまま、MCPクライアントに mcp_server.py をstdioサーバーとして登録してください。設定例は docs/mcp-config.json と docs/codex-config.toml にあります。

studio_state → studio_asset → studio_edit
→ studio_validate → studio_preview → studio_export

AIも更新番号を指定して編集。AI操作は自動的に画面へ反映されます。「出力 / AIに渡す」からテキスト・PNG・ZIPを提出できます。競合した描画は recovery JSON としてダウンロードされます。

原画・色データのエディタです。ゲームのVDP初期化、画面配置、スプライト属性、インターレースのページ配置は出力先プログラムで行います。実機検証はまだ行っていません。
