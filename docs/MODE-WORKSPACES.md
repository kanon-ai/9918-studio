# 現在の画面: 9918専用

SCREEN 0〜3とSprite mode 1のみを作成・編集します。初回・新規素材は無地です。左に素材と部品一覧、中央にキャンバス、横に戻す・パレットを配置しています。他VDPの既存データは保存時も保持されます。以下には以前の汎用UIの説明も含まれます。

# モード別の編集とスタンプ配置

文字素材は一覧で選択し、6×8または8×8を単体編集します。一覧は全体プレビューに統合され、全タイルを実配置のまま表示します。標準は縦横比を保って枠に合わせ、区切り線をON/OFFできます。「1文字を拡大編集」をOFFにすると全体を直接編集できます。

- TEXT: 現在のフレームの全字形で共有する2色を置換。
- SCREEN 1: 選択文字を含む連続8文字の共有色を置換。
- SCREEN 2 / 4: 選択文字の各行の2色を置換。
- P1 / P2: 8×8の4bppタイル選択と編集。
- SPRITE 1 / 2: 透明色を保持して全体／行単位の表示色を置換。未使用色の選択は描画色を選びます。
- ビットマップ: 画素形式を表示。RGB555は各成分を0–31で指定。YJK/YUVは出力時の再構成画像を確認。V9990高解像度は偶数X／奇数Xの色バンク切替。

## スタンプ

1. 文字一覧から部品を選び、単体編集します。
2. 「選択文字をスタンプにする」で現在の部品をコピーします。
3. 必要なら「配置用キャンバスを作成」で同じVDP・モード・パレットの別素材を作ります。
4. 「スタンプ配置」中にキャンバスをクリックすると6×8／8×8のマスへ配置します。右クリックはそのマスを色0で消去します。「戻す」で取り消せます。
5. 配置をOFFにすると単体編集に戻ります。

スタンプはブラウザを開いている間の作業用コピーです。配置済み画素は従来どおり自動保存・JSON・PNG・バイナリ出力の対象です。元部品の後編集は配置済み画素には反映されません。参照型タイルマップやネームテーブルの出力ではありません。異なるモード／VDP／パレットへの配置は無効になります。色共有制約は従来の検証が適用されます。
